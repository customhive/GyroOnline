# LoL由来ブレード 修正案（叩き台）

2026-10-11 作成。出どころは LoL JP Wiki の各チャンピオンページ（スキル表）。
エコーとパイクは反映済みなので載せていない。残り31体ぶん。

各キャラは「今の実装とどこが違うか」と「どう直すか」だけを書いている。
**太字の「相談」** は、決めてもらわないと進められない点。

## 合意済みのルール（再掲）

- HP→回転数、通常攻撃(AA)→体当たり、マナなし
- 距離は 100→1。自分の中心から相手の縁までで測る
- CDは最大ランクの値。必殺技はゲージ制
- スタン・打ち上げは 0.6倍。スロウの強さと持続はそのまま
- ミニオン・味方・ゴールド・キル時リセットは削る
- カモフラージュは入れない
- 「次のAAが特殊な動き」は同じキーの再発動で出す
- パッシブ欄は作らない。スキルに畳むか、削る
- LoLの数値を勝手に変えない

## 先に決めたい共通の論点（8つ）

多くのキャラにまたがるので、ここが決まると個別の案がほぼ確定する。

| # | 論点 | 私の案 | 関係するキャラ |
|---|---|---|---|
| 1 | **遠距離キャラの通常攻撃**。体当たりに読み替えると「4発目が強い」「撃つたび弾薬が減る」が成り立たない | キャラごとにQへ畳む（ゼリはもともとQ＝通常攻撃）。新しい攻撃キーは作らない | ジン、ゼリ、アジール、アフェリオス、ザヤ、サミーラ |
| 2 | **対象指定スキル**（相手をクリックして必中）の扱い | 照準なし。押すと射程内の相手に必ず当たる。射程外なら「射程外」 | アニビアE、ルブランQ、ベイガーR、ヴァイR、リーシンR、セトR、ポッピーE、シンジドE、モルデR、ダリウスR(※指定済み) |
| 3 | **Rが切り札でないキャラ**。ゾーイRはCD5秒の移動技、サミーラRはランクS限定、アニビアRは切り替え式 | そのキャラだけゲージを使わず、LoLどおりの条件にする | ゾーイ、サミーラ、アニビア、アフェリオス |
| 4 | **スネア**（動けないがスキルは使える）。今はスタンで代用している | 新しい状態として作る。時間は0.6倍 | ラックスQ、ジンW、ルブランE、ザヤE、フェイ、アフェリオス |
| 5 | **長い強化**。シンジドR 25秒、リヴェンR 15秒は75秒のラウンドでは長い | そのまま入れて、強さの数値で調整する | シンジド、リヴェン、エイトロックス |
| 6 | **ヤスオRの猶予**。打ち上げを0.6倍にすると竜巻が0.54秒になり、Rを押す時間がほぼない | 打ち上げは0.6倍のまま。Rは「打ち上げ終了から0.3秒後まで」押せるようにする | ヤスオ |
| 7 | **スキル枠がパッシブだけ**のもの（ヴァイW）。キーを押しても何も起きない | スキル欄に「常時効果」として載せる。キーは無反応 | ヴァイW |
| 8 | **象徴的だがスキルではないもの**。アニビアの卵、ザーヘンの復活 | アニビアの卵は説明なしで残す（見れば分かる）。ザーヘンの復活は削る | アニビア、ザーヘン |

### 進み具合

- 反映済み（`npm run fidelity` で行ごとに確認）：エコー、パイク、リヴェン、ダリウス、シンジド、エズリアル、ベイガー、グラガス、アーリ、アニビア、ルブラン、ラックス、リー・シン、ポッピー、セト、ロック、ザーヘン、ヴァイ、ゼリ、オレリオン・ソル、ザヤ、モルデカイザー、ゼド、ヤスオ、エイトロックス、ジン、ハイマーディンガー、ガングプランク
- 回答済みの相談：アニビアの卵は3秒のまま／リーシンRは「自分から見て相手の向こう側」へ蹴る／ロックRは処刑で自動的に+0.5%（次ラウンドへ持ち越し）
- 追加の決定：ポッピーRは「ほぼ場外」になる非常に強い吹き飛ばし（確定ではない）。ルブランのRで再演したQは印が2倍。エズリアルWの印はスキルでのみ炸裂、Eは移動先で止まる
- 追加の決定：オレリオン・ソルの星屑はラウンドをまたいで持ち越す。ゼリのQは1発を弱くしてマシンガンのように連射（毎秒約7.5発）
- 追加の決定：ザヤWは「W中は体当たりのたびに貫通する羽根が1枚飛ぶ」。モルデカイザーRは輪に閉じ込めるのをやめ「5秒間、受けるダメージ半分・与えるダメージ2倍」
- 追加の決定：ヤスオはE中のQ（突進の終わりに周囲を斬る、竜巻なら周囲打ち上げ）を追加。Eは待ち時間6秒、当てたら2秒以内にもう1回（+25%）。Qの突きは射程4.5に短縮。打ち上げ1.2秒はそのまま。エコーのホログラムとつながる帯は削除
- 追加の決定：ガングプランクの樽はLoLと同じ耐久3（時間で1まで減る）。通常攻撃に限らず、ダメージを与えるもの全て（弾・範囲・体当たり、双方）で1ずつ削れ、とどめが持ち主なら爆発、相手なら不発。アジールのEはカーソルに一番近い砂兵へ飛ぶ
- 残り：ゾーイ、サミーラ、フェイ、アフェリオス
- 変えない（試して不満なし）：アジール
- 論点1は「今の方針のまま」で決定（遠距離キャラの通常攻撃はQなどに畳む。ジンの手榴弾だけ削る）
- 論点3は、アニビアは今の6秒固定・ゲージ制のまま。ゾーイRとサミーラRは作るときに相談

### 論点への回答（2026-10-11）

下の各キャラの表は回答前に書いたものなので、食い違う行はこちらを優先する。

- **1**：説明待ち。アジールは今の動き（砂兵が自動で突く）に不満なし → アジールのWの突かせ方は変えない。
- **2**：**対象指定スキルは基本的に作らない**。表の中の「対象指定（論点2）」は、原則として今の照準式のままにする。対象指定がそのキャラの特徴である場合だけ個別に相談する。
- **3**：説明待ち。
- **4**：スネアを作る。
- **5**：強化などの**持続時間はゲームに合わせて調整する**（LoLの値をそのまま使わない）。
- **6**：ヤスオは今の状態に不満なし → **ヤスオは変えない**。
- **7**：スキル枠がパッシブだけのものは「常時効果」として載せる。
- **8**：**復活は入れる**。特徴的なものはパッシブがあってよい。説明文に書くかどうかはその都度判断する。
