# CPU同士の勝率（v0.12.1、HARD対HARD）

2026-10-12 に計測。

## 条件

- 対象：v0.12.1（コミット `2e0a5ff`）
- 両方とも HARD のCPU。1対1、ステージはスタンダード、広さは標準
- 全43キャラの総当たり。同じ組み合わせを先手後手を入れ替えて200ラウンドずつ（同キャラ戦は除く）
- 合計 361,200 ラウンド。1キャラあたり 16,800 試合
- 勝率の誤差はおよそ ±0.7 ポイント
- CPUの予兆時間は、実際のゲームと同じく HARD の倍率（0.8倍）を掛けた（`tools/simtest.mjs` は掛けていないので、そちらの結果とは一致しない）
- 計算の破綻やクラッシュはなし。時間切れの判定は 361,200 ラウンド中1回

## 読むときの注意

- CPUの腕前での結果。CPUは狙いが正確で、弾を横に避けるのがうまい一方、設置物や長押しの使い方は単純。人間同士の強さの順位とは別物
- 1対1だけ。チーム戦や3人以上の強さは測っていない
