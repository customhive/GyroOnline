GYRO CLASH ONLINE（ジャイロクラッシュ オンライン）
=================================================
GYRO CLASH のオンライン対戦版。ブラウザ同士が直接つながる P2P（WebRTC）で対戦する。
サーバーは不要で、GitHub Pages のような静的ホスティングに置くだけで動く。

■ 遊び方
  1. タイトルで「ルームを作る」を押す（ホスト）
  2. 表示された招待URLを相手に送る
  3. 相手がURLを開くと同じロビーに入る
  4. 双方がブレードを選んで「準備OK」→ 対戦開始（2ラウンド先取）
  終了後は「もう一度（ロビーへ）」で同じ相手と再戦できる。CPUとの練習もタイトルから可能。

■ GitHub Pages への公開
  ビルド済みの game.js をリポジトリに含めているので、ビルド工程なしで公開できる。
  1. このフォルダを GitHub のリポジトリに push する
  2. リポジトリの Settings → Pages → Build and deployment
       Source: Deploy from a branch ／ Branch: main ／ フォルダ: / (root)
  3. 数分後に https://<ユーザー名>.github.io/<リポジトリ名>/ で公開される
  招待URLは開いているページのアドレスから作るので、どのURLで公開しても設定は不要。
  src/ を変更したら npm run build を実行して game.js も一緒に commit すること。

■ 通信のしくみ
  接続     PeerJS の公開サーバーが最初の引き合わせ（シグナリング）だけを行い、
           以降のデータはブラウザ間を直接流れる。直接つながらない回線では
           PeerJS 既定の中継（TURN）を経由する。
  権威     ホスト側の物理演算が正。ゲストは入力をホストへ送る。
  先読み   ゲストも同じ演算を手元で走らせ、自分の操作をすぐ反映する。
           ホストの状態が届くたびに「巻き戻し → 未確認の入力を再適用 →
           遅延ぶん早送り」で補正し、ずれは描画側でなめらかに吸収する。
  経路     2本のチャンネルを使い分ける。
             確実・順序保証 … ロビー、入力、ヒットや発動などの出来事
             非保証・順不同 … 状態スナップショットと ping（古いものは捨てる）
  圧縮     スナップショットは量子化したバイナリで 1回およそ 90〜130 バイト、毎秒30回。
           回線が詰まると毎秒15回に落とし、溜まりすぎたら送らずに捨てる。
  その他   ホストのタブが裏に回っても演算が止まらないよう Worker で駆動する。
           オンライン中はヒットストップ／スローを演算に掛けない（時間を共有するため）。

■ 制約
  ・PeerJS の公開サーバーに依存する。止まっている間は新しく部屋を作れない。
  ・企業内ネットワークなど、WebRTC が遮断される環境ではつながらない。
  ・ホスト有利。ゲストは自分の操作が往復遅延ぶん遅れて確定する。
  ・観戦、3人以上、途中再接続（切断後の試合続行）には対応していない。

■ 開発
  npm install           依存（three, peerjs, esbuild）
  npm run build         src/ → game.js（画面左下の版表記 = package.json の version ＋ ビルド日時 を埋め込む）
  npm run dev           監視ビルド
  node serve.cjs        http://127.0.0.1:4181
  npm run simtest       描画なしのバランス確認
  node tools/nettest.mjs [出力先] [URL] [追加フラグ]
                        ブラウザを2つ起動し、実際に P2P でつないでボット同士を戦わせる。
                        例: node tools/nettest.mjs shots http://127.0.0.1:4181/ "norender&lag=100&jitter=20&loss=5"

  URL パラメータ（テスト用）
    ?room=XXXXXX  その部屋に参加      ?host   すぐ部屋を作る
    &auto         自分の操作をボットに任せる   &quick  カウントダウン短縮
    &lag=100&jitter=20&loss=5   遅延(ms)・揺らぎ(ms)・パケット損失(%) を擬似的に加える
    &norender     描画を省く（計測用）

  src/net.js      接続管理（PeerJS、2本のチャンネル、ping、輻輳検知）
  src/netcode.js  スナップショットと出来事の符号化
  src/main.js     進行・入力・ロビー・ホスト／ゲストの同期処理
  その他は GYRO CLASH と同じ（config / sim / ai / view / stage / topmesh / fx / ui / audio）
